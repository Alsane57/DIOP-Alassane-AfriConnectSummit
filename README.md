AfriConnect Summit 2026 — Conférence Tech Panafricaine

Informations Étudiant

Nom : Alassane Diop
Classe : L1 IAGE — ISI
Année : 2026

Description du Projet:

Ce projet consiste à concevoir et développer le site vitrine complet d'une conférence tech fictive panafricaine nommée « AfriConnect Summit »
. Cet événement annuel réunit les développeurs, entrepreneurs et investisseurs du continent africain
. Le site adopte un style web épuré de 2026 avec une typographie expressive, des animations sobres et une navigation fluide
.

Technologies Utilisées:

HTML5 : Structure sémantique rigoureuse avec les balises <header>, <nav>, <main>, <section>, <article>, et <footer>
.
CSS3 : Utilisation de Flexbox (minimum 3 usages) et CSS Grid (minimum 2 usages) pour la mise en page, et de variables personnalisées (:root) pour le Design System
.
JavaScript Vanilla : Toute l'interactivité a été développée en JS pur, sans aucun framework ni bibliothèque externe (ni jQuery, ni Bootstrap CSS)
.
Iconographie : Utilisation de Font Awesome ou Bootstrap Icons via CDN
.
Typographie : Emploi de polices Google Fonts (une expressive pour les titres, une lisible pour le corps)
.

Fonctionnalités JavaScript Implémentées:

Le projet intègre les huit fonctionnalités dynamiques obligatoires réalisées en JavaScript Vanilla
 :
Dark Mode / Light Mode : Basculement du thème via un bouton dans la navbar, avec sauvegarde du choix dans le localStorage pour une persistance entre les pages
.
Navbar Dynamique : Changement de fond et d'ombre de la barre de navigation après 80px de défilement, et menu hamburger fonctionnel sur mobile
.
Animations au Scroll : Apparition progressive des sections (fade-in, slide-in, zoom-in) via l'API IntersectionObserver
.
Compte à rebours : Affichage en temps réel (jours, heures, minutes, secondes) jusqu'à la date de la conférence dans la section Hero
.
Onglets du Programme : Navigation entre les plannings des 3 jours sur la page programme.html sans rechargement de page
.
Filtrage Dynamique : Sur la page intervenants.html, filtrage des cartes par thématique (IA, Business, etc.) sans rechargement
.
Validation de Formulaire : Contrôle complet à la soumission avec messages d'erreur personnalisés et retours visuels (bordures rouges/vertes)
.
Bouton Retour en Haut : Apparition après 300px de défilement avec une remontée fluide
.
